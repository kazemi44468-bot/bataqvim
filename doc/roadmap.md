# نقشه راه

مرحله ۱ — بنیان: ساختار مخزن، مستندات، هسته تاریخ، Calendar، Event و رابط اولیه.

مرحله ۲ — تقویم و رویداد: روز/هفته/ماه/سال، ایجاد و ویرایش رویداد، تکرار، جست‌وجو و مناسبت‌ها.

مرحله ۳ — برنامه‌ریزی: پروژه، برنامه، فعالیت، نقطه عطف، موعد و زمان‌بندی پروژه.

مرحله ۴ — همکاری: کاربران، گروه‌ها، سازمان‌ها، مجوزها و تقویم مشترک.

مرحله ۵ — اعلان: یادآوری، اعلان تغییر و سررسید.

مرحله ۶ — API و اتصال: API v1، احراز هویت، اتصال محصولات و سامانه‌های بیرونی.

مرحله ۷ — محصولات تخصصی: تقویم شهدا، تقویم‌های پروژه‌ای و سایر محصولات.
