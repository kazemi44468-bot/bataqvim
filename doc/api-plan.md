# برنامه API

API برای اتصال وب‌اپلیکیشن، اپلیکیشن موبایل، محصولات تخصصی و سامانه‌های بیرونی طراحی می‌شود.

حوزه‌های اولیه: calendars، events، schedules، reminders، users، groups، organizations، projects، notifications.

نسخه‌بندی از ابتدا در نظر گرفته شود؛ نمونه: /api/v1/.

محصولاتی مانند تقویم شهدا برای داده‌های عمومی تقویم از API هسته استفاده می‌کنند و فقط Endpointهای دامنه‌ای خود را اضافه می‌کنند.
