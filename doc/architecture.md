# معماری فنی

لایه‌ها: Presentation، Application/Services، Domain، Data/API و External Integrations.

core/ هسته دامنه است. platform/ قابلیت‌های مشترک کاربران، گروه‌ها و سازمان‌هاست. products/ محصولات تخصصی است. data/ داده‌های اولیه است. api/ قراردادها و اتصال API است. admin/ مدیریت سامانه است. pages/ صفحات عمومی و assets/ منابع رابط کاربری است.

نسخه اولیه می‌تواند Frontend/Static روی GitHub Pages باشد. وجود api/ به معنی وجود Backend در همین مخزن نیست؛ قرارداد API از ابتدا تعریف می‌شود تا بعداً Backend بدون تغییر اساسی در رابط کاربری متصل شود.
