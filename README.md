# بستر تقویم و رویداد

این مخزن هسته یک سامانه و پلتفرم اختصاصی تقویم، رویداد، برنامه‌ریزی و زمان‌بندی است. هدف، ساخت یک موتور عمومی و توسعه‌پذیر برای مخاطبان عمومی، گروه‌ها، سازمان‌ها و حوزه‌های تخصصی است.

اصل معماری: ابتدا پلتفرم مادر ساخته می‌شود و سپس محصولات و تقویم‌های تخصصی روی آن قرار می‌گیرند؛ از جمله تقویم شخصی، گروهی، سازمانی، پروژه‌ای، آموزشی، فرهنگی و تقویم شهدا.

قابلیت‌های محوری: تقویم روزانه/هفتگی/ماهانه/سالانه، تقویم شمسی، رویداد، برنامه‌ریزی پروژه، رویدادهای تکرارشونده، یادآوری، اعلان، جست‌وجو، آرشیو، دسترسی و اشتراک‌گذاری، API و محصولات تخصصی.

ساختار اولیه: assets/ برای منابع رابط کاربری؛ core/ برای هسته تقویم، رویداد، زمان‌بندی و یادآوری؛ platform/ برای کاربران، گروه‌ها، سازمان‌ها، مجوزها و اعلان‌ها؛ products/ برای محصولات تخصصی؛ data/ برای داده‌های اولیه؛ api/ برای قراردادهای API؛ admin/ برای مدیریت؛ pages/ برای صفحات عمومی؛ doc/ برای مستندات.

جزئیات معماری و نقشه راه در پوشه doc نگهداری می‌شود.
